【概要】
	PC初心者向けの、キーボード入力の練習ソフトです。
	マウスのクリックゲームも付いています。


【アーカイブの内容】
	PCUITraining.X.X.X.zip ･････････ X.X.Xにはバージョンが付与
	└ PCUITraining ････････････････ フォルダ
		├ PCUITraining.exe ････････ 実行ファイル
		├ Readme.txt ･･････････････ このファイル
		└ 他多数 ･･････････････････ 動作に必要なファイル


【インストール】
	適当なフォルダに解凍してください。
	レジストリは使用しません。


【アンインストール】
	フォルダごと削除してください。


【 起動方法 】
	PCUITraining.exe を起動してください。


【 アプリを使う為に 】
	.Net FrameWork 4.6.1 がインストールされている必要があります。
	入ってない方はWindows UpdateかMicrosoftの公式サイトからインストールしてください。（無料です
